# 🚀 Smart Hire – AI-Powered Recruitment System

Smart Hire is a full-stack web application designed to **automate and enhance the hiring process** using AI. It helps recruiters screen candidates efficiently and conduct AI-driven interviews with detailed evaluation.

---

## 💻 GitHub Repository
🔗 https://github.com/vishadhar7/AI-Recruiter 

---

## 🧠 Features

### 🔹 1. Candidate Screening
- Input:
  - Job Title  
  - Required Skills  
  - Number of Positions  
  - Upload Multiple Resumes  
- AI analyzes resumes using Gemini API  
- Ranks candidates based on relevance  
- Returns **Top N candidates** (based on number of positions)

---

### 🔹 2. Interview Assistant
- Input:
  - Resume  
  - Job Title  
  - Job Description  
  - Required Skills  
- Generates **10 personalized interview questions**  
- Accepts candidate responses  
- AI evaluates responses and provides:
  - ✅ Hire / Not Hire Recommendation  
  - 📊 Interview Score  
  - 💬 Personalized Feedback  
  - 📌 Question-wise Analysis
